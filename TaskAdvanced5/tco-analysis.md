# Total Cost of Ownership

Сравнение текущей архитектуры (Camel + DWH) и целевой (Data Mesh + Kafka + Lakehouse) за 3 года.

Все суммы указаны в тысячах рублей.

| Статья затрат | as-is (тыс. рублей)| to-be (тыс. рублей) | Разница |
|---------------|---------------------|-------------------------------|-------------------------|
| Лицензии SQL Server (2008 → 2022) | 3000 | 0 | +3000 |
| Поддержка PowerBuilder | 2000 | 0 | +2000 |
| Облачные VM для DWH (high CPU) | 2400 | 800 (S3 + Kubernetes) | +1600 |
| Облачное хранилище (S3, бэкапы) | 600 | 900 (S3 + Iceberg) | –300 |
| Managed Kafka (Yandex Data Streams) | 0 | 600 | –600 |
| Stream processing (Flink / K8s) | 0 | 500 | –500 |
| Инженеры Data Platform | 4000 | 5000 | –1000 |
| ИТ-поддержка легаси | 1500 | 300 | +1200 |
| **Итого за 3 года** | **13500** | **8100** | **+5400 (экономия 40%)** |

## Обоснование расчётов

| Статья | Исходные допущения |
|--------|--------------------|
| Лицензии SQL Server | Переход с SQL Server 2008 на 2022: ~1 млн руб./год за 8–10 ядер |
| Поддержка PowerBuilder | Внешний контракт ~600–700 тыс. руб./год |
| Облачные VM для DWH | 8–12 vCPU, 64–128 ГБ RAM → ~80 тыс. руб./мес. |
| Целевые VM (S3 + K8s) | Оптимизация за счёт автоскейлинга и меньшего числа узлов → ~22 тыс. руб./мес. |
| Хранилище (DWH) | SSD по 10 руб./ГБ·мес, 5 ТБ → 600 тыс. руб. за 3 года |
| Хранилище (S3 + Iceberg) | S3 по 5 руб./ГБ·мес, 10 ТБ (сырые + история) → 900 тыс. руб. за 3 года |
| Kafka + Flink | Managed Kafka (~20 тыс. руб./мес) + ресурсы Flink → 1100 тыс. руб. за 3 года |
| Инженеры Data Platform | Текущие 2–3 человека (с начислениями ~130 тыс./мес). Целевые — более дорогие специалисты, разница +300 тыс. руб./год |
| Поддержка легаси | Сейчас 0,5 ставки инженера под Camel/PowerBuilder → 500 тыс. руб./год. После миграции — только архивная поддержка |

## Вывод :
- **Снижение затрат**: 35–45% за счёт отказа от проприетарных лицензий и оптимизации инфраструктуры
- **Основной эффект**: отказ от лицензий SQL Server и поддержки PowerBuilder
- **Уменьшение затрат на инфраструктуру**: замена дорогих вычислительных VM на S3 + Kubernetes
- **Ускорение time-to-market**: новые отчёты и витрины выводятся за дни вместо недель
- **Снижение стоимости аналитики**: отчёты строятся в real‑time, без перегрузки DWH
