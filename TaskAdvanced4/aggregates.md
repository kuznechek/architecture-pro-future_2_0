# Aggregates

## Medical context

**Patient**  
Идентификатор: PatientId.  
Включает всю базовую информацию о человеке: ФИО, дата рождения, контакты.  
Нельзя завести медицинскую карту без пациента.  

**MedicalRecord**  
Идентификатор: RecordId.  
Содержит историю болезней, диагнозы, назначения.  
После закрытия записи её нельзя менять, все изменения логируются.  

**Research** (исследование)  
Идентификатор: ResearchId.  
Отвечает за лабораторное или инструментальное исследование, его статус и результаты.  
Результат появляется только после завершения. Если результат готов, можно запускать ИИ-анализ.  
События: `ResearchCompleted`, `AIAnalysisRequested`.

## Fintech context

**LoanAgreement** (кредитный договор)  
Идентификатор: AgreementId.  
Хранит сумму, срок, ставку, график платежей.  
Договор нельзя подписать без одобрения кредитного комитета, а платёж не может быть больше остатка долга.  
События: `LoanAgreementSigned`, `LoanRepaymentStarted`.

**Payment**  
Идентификатор: PaymentId.  
Фиксирует сумму, дату, статус транзакции и ссылку на договор.  
Один и тот же платёж нельзя провести дважды.  
События: `PaymentProcessed`, `PaymentFailed`.

## AI context

**AIModel**  
Идентификатор: ModelId.  
Хранит версию модели, гиперпараметры, метрики.  
Модель можно использовать для анализа только после того, как она прошла валидацию.

## Analytics context

Агрегатов как таковых нет – здесь только витрины для чтения (`DataMart`, `Report`)
